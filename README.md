# Bl3nd — Browser 3D Workspace

Bl3nd is a zero-build, mobile-first browser 3D modeling foundation. The app runs as static HTML/CSS/native JavaScript modules and uses Three.js from a pinned CDN import map.

## First deployment

1. Create a GitHub repository with a `main` branch.
2. Create `.github/workflows/unpack-update.yml` in the GitHub web editor using the exact bootstrap workflow supplied with this release.
3. In repository Settings, set Actions → General → Workflow permissions to **Read and write permissions**. Set Pages → Build and deployment → Source to **GitHub Actions**.
4. Upload `initial-release.zip` into the repository's `uploads/` folder. The action extracts it into the repository root, removes the uploaded ZIP and commits the files. A successful unpack run automatically triggers the GitHub Pages deployment workflow.

The application displays staged startup progress and keeps the exact startup error visible if initialization fails. The progress percentage represents completed initialization phases, not downloaded-byte progress.

The application does not require a build command. Open the GitHub Pages URL after the deployment workflow completes.

## Controls

- `Tab`: Object/Edit Mode
- `G`, `R`, `S`: start Move, Rotate or Scale; move the pointer to preview
- Free `G` follows the current camera view plane, so screen-right/screen-up move with the current view
- `X`, `Y`, `Z`: constrain to an axis; `Shift + X/Y/Z`: constrain move/scale to the plane perpendicular to that axis
- `,` during a transform toggles **Global / Local** orientation. Global is the default; Local uses the object's world-space starting axes for axis-constrained Move, Rotate and Scale. The mobile transform pad has the same toggle.
- Optional axis snapping is shared by `G`, `R` and `S` when constrained with `X/Y/Z`. It is off by default; Move uses world-unit steps, Rotate uses degree steps (15° by default), and Scale snaps factor changes around 1.0 (0.1 by default). Global and Local steps are configured separately. Typed numeric values remain exact; free movement/trackball and Shift+axis plane constraints are not changed. On mobile the SNAP and STEP SIZE controls appear inside the active transform pad; desktop settings are in Scene properties.
- Free `R` uses a camera-oriented virtual trackball; `R` + `X/Y/Z` rotates around the chosen Global or Local axis
- While `G/R/S` is active, a passive viewport guide marks the live transform pivot, Global/Local X/Y/Z axes, and the active move/scale plane or rotation ring. It is visual feedback only; it does not intercept pointer/touch input or act as a draggable gizmo.
- **Pivot Point** in Scene properties offers Median Point, Bounding Box Center, Individual Origins and 3D Cursor. In Edit Mode, Median Point uses the unique selected vertices and Bounding Box Center uses their local-space extents; in Object Mode, Bounding Box Center uses the mesh world-space bounds. 3D Cursor remains fixed while transforming. Edit Mode Individual Origins now resolves one median pivot per disconnected selected region: selected faces merge when they share a topology vertex, selected edges merge through shared endpoints, and selected vertices merge only across real edges between selected vertices. Shared vertices remain welded and belong to one region, so the operation never duplicates topology to create conflicting pivots. The viewport guide marks each region origin. Object Mode still has one active object, so Individual Origins coincides with that object's origin; multi-object aggregation is not implemented.
- Numeric keys, `Enter`, `Esc`: enter a value, apply, cancel
- Press `G/R/S` with the pointer over the viewport to begin there; otherwise the viewport center is used
- Edit Mode `1/2/3`: vertex/edge/face selection; selected topology is drawn directly over the mesh
- Edit Mode `Shift-click`: add/remove elements; `A`: select all; `Alt+A`: deselect; `Ctrl+I`: invert selection
- Edit Mode `B` / `C` / `L`: Box / Circle / Lasso selection; `Esc` returns to click selection. Hold `Shift` while dragging to add.
- Edge Select: select one or more seed edges, then `Alt+L` expands through opposite edges of connected quads; `Ctrl+Alt+L` follows opposite edges through closed all-quad vertex fans. At extraordinary poles, it pairs only a unique near-antiparallel edge direction (at least 155° apart with a clear best match); boundaries, mixed-face fans, non-manifold fans and ambiguous pairings are skipped. The Select menu exposes both operations.
- Edit Mode `X` / `Delete`: delete selected topology; `Shift+X`: dissolve selected topology; the viewport Select menu offers the same actions.
- Face Select `E` / `I`: start modal Extrude / Inset previews. Drag vertically, type a value, use arrow keys to nudge, Enter applies one undoable operation, and Esc cancels. Extrude accepts one connected, coplanar face region with a single simple boundary, including concave regions and tilted geometry; it follows the region's actual plane normal and supports positive or negative distance. Inset accepts one face or one connected, coplanar face region with a simple boundary. Both use shared read-only face-region analysis for ordered boundary extraction; holes, multiple loops, disconnected selections and non-planar regions remain explicitly unsupported by these operations.
- When a modal face/edge operation starts with multiple faces involved, Bl3nd recenters the viewport on that selected area and chooses an angle that maximizes the combined visible projected area of the selected planes. For selections on opposite sides of an object, one camera angle cannot show every side at once; orbit to inspect the hidden surfaces. A single selected face/edge is left in the current view. In Face Bevel **Individual Faces** mode, the camera instead focuses the current face target and reorients whenever Previous/Next Face changes, including faces on the back or side of the object. Width/height/segment/profile edits keep the camera on the active face.
- Face Select: choose faces and press `Ctrl+B` or **Bevel**. Face Bevel starts in **Region** mode for one connected planar region, preserving shared inner seams across multi-row/multi-column grids. A small connected non-planar patch with one simple boundary and smoothly varying adjacent face normals can start in **Continuous Surface** mode: selected top faces remain welded, vertex offsets follow area-weighted smooth normals, and the transition band is triangulated and checked for folds/topology errors. A spatially filtered triangle-intersection screen also checks the changed top/transition triangles against the rest of the candidate mesh and rejects detected crossings without mutating the source. This is a conservative partial check, not a proof of global collision freedom; whole-sphere/high-curvature bevels are not supported. Sharp creases, holes, disconnected regions, strongly curved/ambiguous normals and unsafe offsets fall back to **Individual Faces** when possible or reject without mutation. Press `I` (or tap the mode button on mobile) to switch between Continuous Surface / Individual Faces on eligible curved patches, or Region / Individual Faces on planar patches. In Individual mode, use the mobile previous/next face buttons or desktop `PageUp` / `PageDown` to target a face, then adjust that face's own width, height, segment count and profile. Press `H` to switch width/height. Individual Faces creates separate panels/grooves; it is not the continuous curved transition. Switching from Individual mode to a shared operation requires all per-face settings to match and the combined candidate to pass validation.
- Edge Select: select one supported interior edge, exactly two adjacent edges at one closed tri-valent corner, one simple connected path of three to eight consecutive edges (shared-face miters and triangulated cap patches for valence-four through valence-six terminal and internal junctions), two to four separate two-edge miter pairs (up to eight selected edges), or up to eight pairwise-disjoint interior edges, then use `Ctrl+B` or **Bevel** in the Edit Mesh panel. Drag horizontally to preview width; hold `Shift` for precision, use `←/→` for small width changes or type a factor from `0.01` to `0.95`. `Enter` applies the preview in one undoable operation; `Esc` or right-click cancels. On mobile, drag or use the on-screen numeric pad. Every chain vertex recovers its ordered opposite fan arc. Valence-four caps use one triangle; valence-five/six caps use a center-fanned triangle patch. Cap winding must oppose every existing boundary edge. Four- through seven-edge paths are regression-tested across every simple path on a cube, and mixed tri-/valence-four/five/six fixtures cover multi-junction chains. Branches, cycles, mixed connected/disconnected selections and overlapping independent neighborhoods are rejected. Convex planar boundary-free source neighborhoods are required; both endpoints and internal junctions may have closed valence-three through valence-six fans. Valence-five/six patches use reduced profile amplitude to avoid foldovers. Fans above valence six, boundaries, non-manifold topology and ambiguous cap boundaries are rejected without mutation.
- Edge Select: select exactly one seed edge, then `Ctrl+R` or **Loop Cut** in the Edit Mesh panel. Drag horizontally to slide the live cut preview; hold `Shift` for precision, use `←/→` for 1% steps (Shift for 0.1%), or type an offset from `0` to `1`. `Enter` applies and `Esc` cancels. Use the mouse wheel or `+` / `-` to adjust 1–8 evenly spaced cuts; all cuts slide together. On mobile, drag in the viewport, type the slide value, or use the on-screen cut-count buttons.
- `Shift + A`: add menu; `Z`: shading menu
- Numpad `1/3/7`: front/right/top views; scroll: zoom
- Desktop: left-drag or middle-drag to orbit; right-drag or Shift+left-drag to pan; scroll to zoom; a stationary click selects
- Mobile: one-finger orbit, two-finger pan/zoom, long-press to place cursor and bottom quick actions; choose Box / Circle / Lasso from the viewport Select menu for drag selection, then return to Click Select to orbit with one finger. Face operations use the on-screen numeric pad; drag vertically to preview, Apply to commit or Cancel to restore.
- Edit Mesh panel: Delete and Dissolve use the active vertex/edge/face selection; Validate Mesh reports topology problems, and Repair Safe Issues handles only conservative repairs. Loop Cut is available from the panel or Ctrl+R while one seed edge is selected. Bevel is available from the panel or Ctrl+B. In Face Select, Region mode handles one connected planar face patch with one simple boundary; Individual Faces mode processes selected polygons separately and stores independent per-face width, height, segments and profile. Non-planar connected selections automatically enter Individual mode when every polygon is individually supported. Edge Select retains the existing supported edge, adjacent-pair, connected-chain and disjoint-edge templates. Both Face Bevel modes use 1–8 segments and a 0–1 concave/rounded/convex profile. Region mode retains shared top seams; Individual mode intentionally separates adjacent raised panels with a transition around each face. Unsupported faces reject the complete operation without mutation.
- Concave planar polygons are ear-clipped for rendering and selection. Dissolve can merge a simple concave planar patch; non-planar, self-intersecting and non-manifold patches remain unchanged.

Run all topology/operator regression tests with Node: `node --experimental-default-type=module --test tests/*.test.js`.

See [`HANDOFF.md`](./HANDOFF.md) for architecture, exact implementation status, limitations and roadmap. This is an initial engineering foundation, not yet a feature-for-feature Blender clone.


### Safe topology repair

In Edit Mode, **Repair Safe Issues** removes malformed faces and duplicate faces, reorients consistently orientable manifold face components, and compacts unused vertices. It deliberately does not guess how to repair non-manifold edges, non-planar faces, self-intersections, or contradictory/non-orientable components; those remain in the validation report for manual correction. Use **Validate Mesh** before and after repair to inspect what changed.

### Extrude and Inset

In Face Select mode, select one face or a connected planar face region and press `E` or `I` (or use the Edit Mesh panel). Both operations preview from the immutable source mesh. Drag vertically to adjust, type a numeric value, use arrow keys to nudge, press `Enter` to commit one undo step, or `Esc` to restore the original. Extrude accepts one face or one connected, consistently wound, coplanar region with a single simple boundary. It derives direction from the region boundary's Newell normal (rather than averaging face normals), so concave and arbitrarily rotated planar regions use the correct world-space direction. Both operations consume `HalfEdgeMesh.analyzeFaceRegion()`, which exposes connected face components, ordered boundary loops, nested holes, region-facing convex/reflex corners, winding and planarity without mutating the mesh. Candidate geometry is built privately, checked for topology and triangulation, then committed atomically; disconnected regions, holes/multiple loops, invalid source meshes and invalid distances reject without changing the source. Positive and negative distances are supported. Inset offsets the entire selected region boundary inward by a consistent distance based on the shortest boundary edge. Shared corners use miter intersections, and original internal face edges are retained in the inner region. Simple concave regions are supported when the offset remains inside and simple. Disconnected selections, holes/multiple boundary loops, non-planar or inconsistently wound regions, excessive miters, self-intersections and offsets that collapse/fold a face reject without changing the source. The amount is a fraction of the shortest boundary edge; the actual world-space offset distance is shown during preview and after applying. This is a conservative planar-region inset, not Blender's full BMesh/individual-face inset parity.

### Bevel

**Face Bevel:** In Face Select mode, press `Ctrl+B` or choose **Bevel**. Region mode raises one connected planar region and keeps its internal seams welded. It supports 1–8 transition segments, a Profile (`0` concave, `0.50` rounded, `1` convex) and independent width/height factors from 0.01–0.95. Press `H` to switch the active drag/numeric parameter; on mobile use Height +/- and Edit Width/Height. Press `I` or the mobile mode button to switch to **Individual Faces**. Individual mode keeps a separate settings record for each selected face: use PageUp/PageDown on desktop or the mobile previous/next face controls, then set that face's width, height, segments and profile without changing the other selected faces. The operation is rebuilt from the immutable source and validated as one transaction; `Enter` applies one undo step and `Esc`/right-click restores everything. Non-planar connected selections automatically use Individual mode when each selected polygon is itself planar and safely bevelable. Adjacent selected faces then become separate raised panels with their own perimeter transitions and a groove at their shared base edge; they do not form one smooth continuous curved transition. Switching back to Region mode requires matching per-face settings and a valid planar combined region. Acute/excessive miters, non-planar individual polygons, invalid topology, folded walls and unsupported candidates reject without source mutation. This is not full Blender Face Bevel parity.

For Edge and Face Bevel, drag horizontally to adjust the active amount and use arrow keys for small adjustments. Hold `Shift` for precision. Use `+`/`-` to change segments and `[`/`]` to change profile; hold `Shift` with bracket keys for 0.01 profile steps. For Face Bevel, press `H` to switch width/height; press `I` to switch Region/Individual Faces; in Individual mode use PageUp/PageDown on desktop or the mobile previous/next face controls to choose which selected face receives parameter edits. Each face stores its own width, height, segments and profile. The mobile pad includes Height +/- and Edit Width/Height controls. After any mesh modal operation finishes, click selection is restored so the next touch drag can orbit the viewport immediately.

Select one edge in Edge Select mode on a closed manifold mesh. The single-edge template is limited to an edge whose two endpoints each have exactly three incident faces, with all four affected faces simple, planar and convex. It replaces the selected edge with a bevel strip and selects its new perimeter.

Connected bevel supports exactly two adjacent edges sharing one closed, tri-valent corner, or one simple path of three to eight consecutive selected edges. The two-edge case intersects offset lines in the common face, creates one shared miter edge and adds two joined bevel strips. Longer chains create one shared-face miter at each internal vertex and close both terminal ends with fan-aware cap patches when needed. Both endpoints and internal junctions may have closed valence-three, -four, -five or -six fans. The ordered opposite fan arc is trimmed at every non-selected radial edge. Valence-four junctions receive one triangular patch; valence-five/six junctions receive center-fanned triangle patches, with one uniquely oriented outer boundary and individually planar triangles. The fan boundary must be simple and convex in its stable projection. Mixed-valence chain regressions cover repeated cap patches, reversed path order, rotated geometry, all 1–8 segment counts and zero-boundary topology. If any chain vertex has valence five or six, profile amplitude is conservatively scaled to 25% to avoid foldovers; the modal reports this limit only when using multiple segments. The exhaustive cube regressions cover all 360 simple tri-valent paths of four through seven edges, and a segmented eight-edge path passes on a closed pentagonal prism. Cycles, branches, mixed connected/disconnected selections, valence above six at either endpoint or internal junction, overlapping cap regions and ambiguous miter intersections are rejected before source mutation. You can also select two to four separate two-edge pairs and process their miter junctions in one transaction when their affected face neighborhoods are disjoint. Alternatively, select up to eight pairwise-disjoint single edges to bevel independent neighborhoods together. The amount is a normalized factor of the safe maximum (45% of the shortest neighboring edge), not a world-unit distance.

Bevel supports **1–8 segments** across each accepted single-edge, connected pair/chain, and disconnected-edge combination. One segment keeps the original strip topology. With multiple segments, the strip is divided into intermediate rows and triangulated per segment; shared miter rows reuse the same vertices so adjacent strips stay connected. The **Profile** control shapes the intermediate cross-section points inside the terminal cap planes: `0` is concave, `0.50` is the default rounded profile, and `1` is convex. Profile shaping is active with two or more segments; the shared miter seam itself stays straight. Candidate topology and triangulation are validated before any source replacement.

Press **Ctrl+B** or choose **Bevel** in the Edit Mesh panel. Drag horizontally, hold `Shift` for width precision, use arrow keys to nudge width, or type an amount from `0.01` to `0.95`. Press `+`/`-` to change segments and `[`/`]` to change profile; Shift with the bracket keys makes fine `0.01` profile adjustments. On mobile, use the on-screen segment and profile +/- rows. `Enter` commits one undoable operation; `Esc` or right-click restores the original mesh. Every preview is rebuilt from the original source, and the complete candidate is topology-validated before commit. Boundary edges, non-manifold or inconsistently wound meshes, existing topology warnings, non-planar/concave faces, fans above valence six, ambiguous miter intersections and excessive miters are rejected without mutation. Chains longer than eight selected edges, branches, cycles, mixed connected/disconnected selections, internal junctions above valence six and open-boundary bevels remain unsupported.

### Loop Cut

Select exactly one edge in Edge Select mode, then press **Ctrl+R** or use **Loop Cut** in the Edit Mesh panel. The operation follows the quad-opposite edge loop and previews 1–8 evenly spaced cuts, sharing an interpolated vertex per cut and crossed edge. Drag horizontally to slide the cut group; hold `Shift` for fine movement, use arrow keys for small nudges, or type a group offset between `0` and `1`. Use the mouse wheel or `+` / `-` to change the number of cuts. `Enter` commits one undoable operation; `Esc` or right-click restores the original mesh. Mobile users can drag, enter an offset, or use the on-screen cut-count controls. Each crossed quad is split into `cuts + 1` quads and all new cut edges remain selected. It currently accepts only consistently wound, convex, planar quad strips. Non-manifold, non-quad, concave, non-planar, or inconsistently wound paths are rejected before mutation. Loop Cut itself still stops at extraordinary poles; the pole-aware behavior currently applies only to Edge Ring selection. N-gons, multiple distinct seed loops and Blender-equivalent edge sliding remain unsupported.
